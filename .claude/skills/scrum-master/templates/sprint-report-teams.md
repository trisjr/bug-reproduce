# Sprint Report Template for Microsoft Teams

Sử dụng template này để gửi báo cáo tình hình Sprint lên channel Teams.
Các biến trong ngoặc nhọn `{}` cần được thay thế bằng dữ liệu thực tế.

---

🚀 [Sprint {sprint_name} Report] Tình hình tiến độ dự án

📊 TỔNG QUAN:
- Tổng số task: {total_tasks}
- Hoàn thành (Release/Pass/Resolved): {completed_tasks} task (~{completion_rate}%)
- Tồn đọng (To Do/In Progress): {remaining_tasks} task (~{remaining_rate}%)

🔴 CẢNH BÁO TIẾN ĐỘ (High Risk):
Các task quan trọng cần lưu ý đặc biệt:
{high_risk_list}
*(Format: 1. Tên Task (Assignee) -> Vấn đề/Lý do)*

👉 ACTION REQUIRED:
- Check lại các task 'Passed' để chuyển sang 'Released'.
- Cập nhật đúng status 'In Progress' cho task đang làm.
- Report blocker ngay lập tức nếu có.

Goal: {sprint_goal} 💪
